# Security Policy

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub Issues.**

If you discover a security vulnerability, please report it responsibly by emailing:

📧 **pavanpitiwaduge@gmail.com**

Please include as much of the following as possible:

- A description of the vulnerability and its potential impact
- Steps to reproduce the issue
- Any relevant URLs or file paths
- Your contact details (if you'd like to be credited)

Thank you for helping keep OAEG and its community safe!
